# 0.1.0a13

**修掉两类让人以为「坏了」的毛病：启动白屏、确认框跑到屏幕外；同时把「存档」页换成游戏里真正的存档列表，并给「按战役/版本分档」加了开关（默认关闭）。**

## 升级方式

覆盖可执行文件即可。战役库、设置与存档分别在游戏目录同级的 `miyin_launcher_data/` 和「我的文档」里，本版升级不动它们。之前打开过「按战役隔离存档」的保持原样；没打开过的仍是关闭。

## 修掉的问题

| 症状 | 现在 |
| --- | --- |
| 启动器启动后白屏，或数据多时要白屏很久 | 启动时的数据迁移与合并挪到后台，先显示「正在准备数据…」，不会停在纯白；出错时会显示原因和「重新加载」 |
| 系统缺少 WebView2 运行时，双击没反应或只剩白窗 | 直接弹中文说明 + 官方下载地址，不再闪退 / 白窗 |
| 自制战役地图一多，点「删除」后确认框在屏幕外，要滚下去才点得到 | 所有确认框都按当前窗口居中 |
| 下拉框在滚动区域里被裁掉或错位 | 弹层不再被滚动容器裁切 |
| 程序崩溃时拿不到现场 | 程序目录会写 `miyin-crash.log`，反馈时附上即可 |

## 存档页：先让你看见游戏里真正的存档

「存档」页以前读 `Documents\StarCraft II\Banks`，不少机器上那是空的。现在读的是游戏真正在用的存档（`Accounts/<账号>/<地域>/Saves` 下的 `.SC2Save`），和游戏里「加载游戏」看到的是同一批：

- 按战役分区（自由之翼 / 虫群之心 / 虚空之遗 / 诺娃 / 未归类），可按账号或位置筛选；
- 每份显示时间、大小、账号与地域、所在文件夹。

这一页目前**只读**：归类、备份与切换还在做（下一轮）。

## 按战役 / 版本隔离存档（默认关闭）

同一部战役的多个版本以前共用一份进度：切到新版本玩一半，再切回来读到的是新版本的。去设置页打开「按战役隔离存档」之后：

- 原版与每个导入的版本各有一组进度；启用哪个版本就切到它自己那组，切回来进度还在；
- 第一次打开会把当前这份存成「原版」，不会丢进度；
- 设置页能看到已经存下的组，切过去 / 还原 / 改归属；旧版本用过的组会自动迁移过来，不会消失。

**默认关闭**：没有打开时启动器不碰 `Banks`。想用再去设置页勾上。
