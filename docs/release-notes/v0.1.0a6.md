# 0.1.0a6

**这一版的主题：给包作者一个能做事的工具，同时把"往游戏目录里写东西"这件事管住。**

## 开发者页（新）

设置页 →「开发者页」，或顶栏的「开发 · 实验」。

- **独立入口**（React + JetBrains 官方 Ring UI），和用户侧不共用运行时 —— 用户侧一个字节都没变大。
- **扫游戏目录**：完整扫，勾一个目录 = 勾住它底下所有东西（**空目录也算**，作者要留空壳子是他的自由）。
- **看文件**：文本按行打开、图片直接显示、二进制明确告诉你打不开并给两条出路。
- **编辑器标签页**、搜索、右键菜单（打开 / 勾选 / 复制路径 / 在资源管理器里打开 / 设为封面 / 设为说明书）。
- **包信息可编辑**：名称 / 作者 / 版本（带校验）/ 注册 ID / 标签 / 归属 / 类型 / 模组 ID / 依赖 / 说明 / 封面 / 说明书 / 主地图（只有自制战役才有这一项）。
- **导出压缩包**：选文件 → 填信息 → 导出，**带进度条**。包内保持游戏目录里的相对路径，附 `metadata.json` 与 CCM 认的 `metadata.txt`。
- **状态持久化**：勾选、包信息、封面与说明书路径都存本地 —— 重开页面、重启启动器都还在。

> 版本管理（提交 / 日志）代码写了但**暂时隐藏**：它只记路径 + 大小 + 修改时间，
> 给不了「内容回退」。等接上 SC2Diff 再打开，不做半成品糊弄人。

## 写盘：放开，但管住

- **落点放开到整个安装目录**：出目录（`..` / 绝对路径 / 盘符）一律拒绝，目录里任意位置允许覆盖 —— 复刻战役那种整包结构终于装得进去。
- **铺盘前先给用户看**：新增 / 覆盖 / 接管 / 删除各几项、共多少字节，点头才动。
- **动之前先备份**：被覆盖或删除的既有文件先进 `data/backup/`，切回原版时原样还原。
- **游戏运行时拦一道**：开着游戏不给切换（运行中的文件删不掉，会留下记了一半的清单）。

## 存档管理（issue #20）

- 看 / 备份 / 还原 `Documents\StarCraft II\Banks`；还原前自动把现存那份另存为「还原前-时间戳」。
- **按战役隔离**（默认关，用户主动打开）：打开那一刻把当前进度收成「原版」，之后每个战役用自己的那份；可以手动把某一份指给别的战役。

## 包格式

- **v3 覆盖规则生效**：`miyin.overrides` 三种写法（原样覆盖 / 前缀映射 / 单文件），`to` 一律当目录用。
- `Interfaces/` 进镜像识别，界面 Mod 从此落得进去。
- `miyin.format` 按**实际用到的最高档**声明（基础 1 / 补丁字段 2 / 覆盖规则 3）；启动器支持到 3。
- 导出补一份 CCM 的 `metadata.txt`，别家工具也认。

## 界面

- **主题三档**：跟随系统（默认）/ 日间 / 夜间。夜间配色照 IntelliJ New UI Dark 重做。
- 顶栏从 62px 收到 48px。

## 修掉的问题

- release 白屏：两个入口塞进同一次构建，用户侧加载到了开发者页的挂载代码。
- 点开发者页进不去：主构建把 `dist/ide.html` 抹了。
- `pnpm install` 非零退出（core-js 的安装脚本没人放行），CI 也会红。
- 导出的 `metadata.json` 顶层多写了个约定里没有的 `format`，且和 `miyin.format` 自相矛盾。
- 大包导出拿到的文件没有元数据：现在 `metadata.json` **第一条写**，并给了进度条。
- 战役停用后它带来的模组还留在游戏目录里（现在跟着战役走）；落点撞车会点名说清谁盖了谁。
