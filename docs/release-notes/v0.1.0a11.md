# 0.1.0a11

修复安装时的大小写问题。

## 包里的 maps/ 现在会被当成 Maps/

Windows 的文件系统不分大小写 —— 包里的 maps/Campaign/void/x.SC2Map 和 Maps/Campaign/void/x.SC2Map
落盘之后是同一个地方。但启动器以前按**区分大小写**比较，认不出小写 maps/，
于是把它当成「作者的分类目录」，整包塞成 Maps/maps/…，游戏就找不到这些地图了。

现在：

- maps/、Mods/、Interfaces/ 一律按大小写不敏感识别，落盘用**规范拼写**（Maps/…）；
- 平坦的 maps/01.SC2Map（作者的分类习惯，不是镜像）仍然照旧拍平到游戏会扫描的位置；
- 规范的 Maps/Starcraft Mass Recall/…（复刻战役那种）保持原路径不动 ——
  它的启动器地图按相对 Maps/ 的路径联动关卡，拍平就进不去关了。

**如果你之前装过这种包**：库里那个版本的落点还是错的，删掉它重新导入一次即可。
