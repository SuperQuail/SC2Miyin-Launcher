# 0.1.0a15

**星际枢纽（SCNexus）托管的战役可以直接在弥音启动器里看到、一键转为自己的托管；导出也支持弥音包与星际枢纽兼容包两种格式。**

## 星际枢纽托管检测

- 启动时读取星际枢纽的 `SCNexusStorage` 配置与战役库，在对应资料片页显示「来自星际枢纽」卡片；
  卡片左上角标「来自于：星际枢纽」。
- 「转为启动器托管」会先弹确认框：说明会复制到启动器库；**「转换后删除星际枢纽里的副本」默认不勾**，
  正在星际枢纽里启用的条目不允许删源。
- 转换复用现有导入链路，转过来的版本照常启用、导出、挂补丁。

## 导出向导

- 导出时可选 **弥音包格式**（完整保真，推荐）或 **星际枢纽兼容包**。
- 星际枢纽格式会先逐条列出**会丢失的内容**（补丁绑定、封面、说明、模组勾选配置、
  自制战役等），不会在用户没看见代价前写文件。
- 用真实战役库的 LOTV / WOL / HOTS 版本做了导出 → 枢纽安装仿真，地图/模组文件逐字节一致。

## 稳定性 / 体验

- 内嵌 7-Zip 26.05：7z / rar / 加密包统一用内置 7z 解压，不再依赖系统的 tar / unrar。
- 单实例锁、右下角托盘图标、按需提权（写游戏目录被拒时才弹一次 UAC）与启动失败原生提示。
- 修复启用战役被拒时前缀被吞、不弹提权的问题。

## 升级方式

覆盖可执行文件即可。战役库、设置与存档在游戏目录同级的 `miyin_launcher_data/` 和「我的文档」里，
本版升级不动它们。

## 关于本版本

- 有界面改动（星际枢纽卡片、导出向导）。
- 没有改战役包格式，旧包照旧可用；导入仍兼容 CCM / 星际枢纽 / 镜像包。
