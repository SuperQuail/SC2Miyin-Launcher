# 0.1.0a20

改版编辑页、按改版补丁绑定、固定操作栏，以及默认夜间主题。

## 改版独立编辑页

- 选中改版后，从底部固定操作栏进入「编辑版本」；不再给每张卡片单独加按钮。
- 编辑页内可切换同战役的改版、启用、开始游戏。
- 页签：补丁 / 模组 / 地图 / 文件。

## 补丁按改版绑定

- 补丁绑定从「槽位」改为「槽位/改版」；启用与优先级按改版独立。
- 旧 v1 索引载入时自动迁移，迁移前留 `library.json.v1.bak`。
- 旧的无归属补丁迁移到全部现有改版；原有的槽位绑定展开到该槽位每个改版。
- 新导入补丁 / 新导入改版默认互相全挂。
- 补丁面板只保留启用复选框、优先级、重命名、删除。

## 界面

- 战役页底部操作栏改为固定玻璃条，不随内容滚动。
- 战役卡片改为半透明。
- 启动器默认夜间主题，不再跟随系统。

## 已知限制

- 改版卡片拖动排序暂时禁用：指针拖动在真实窗口里会乱飘，等修好再开。
- 独立编辑页目前只接官方战役；自制战役仍用原页面。
