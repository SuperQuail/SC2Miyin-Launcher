# 0.1.0a12

两个新功能：启用前的跨战役冲突警告、自制战役页的启用确认。

## 启用战役时，会先告诉你它和谁撞车

多个战役可以同时启用，但它们可能都要往游戏目录的同一个位置写文件。以前是后启用的**静默覆盖**
前一个，你根本不知道。

现在点「启用」会先查一遍（只读，什么都还没写）：有冲突就弹对话框，列清楚要撞的位置、
每一条**被哪个战役的哪个版本占着**，然后让你选 **「启用 <新战役>」** 还是 **「启用 <另一个>」**。
选后者就什么都不改。

判定只算**战役之间**：没启用的版本不占位置；同一个战役换自己的版本不算冲突。

## 自制战役页的「启用」现在有确认框了

以前自制战役页第一次点「启用」什么都不发生（确认框从来没渲染过）—— 这是真 bug，已修。
现在和官方战役页一样：先看预演，确认后才写盘。
