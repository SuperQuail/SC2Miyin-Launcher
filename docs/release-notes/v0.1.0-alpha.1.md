# v0.1.0-alpha.1 —— 第一个能用的版本

> 这是**预发行版**。核心链路（导入 → 识别 → 启用 → 打补丁 → 导出）已经跑通并有测试覆盖，
> 但界面细节和边界情况还会变。欢迎拿真实包来砸。

## 这个版本能做什么

### 战役库：同一个战役多版本共存

游戏目录里的 `Maps/CustomCampaigns` 只能放「当前这一份」，装第二个就得删第一个。
现在库放在**软件同级的 `data/`**，多个玩家版本并存、随时切换，谁都不覆盖谁。

- 主菜单只列**四大战役**（自由之翼 / 虫群之心 / 虚空之遗 / 诺娃），
  进化与序章归并到父战役 —— 目标子目录属于**版本**而不是槽位，所以虫心槽位里
  本体包和进化包能同时存在，各落到正确位置。

### 任意打包形式

zip / 7z / rar / tar / gz / bz2 / xz / zst / cab / iso 都能直接导入，不用先转格式。

实现上没有引入新依赖：Windows 10 1803+ 自带的 `tar.exe` 其实就是
**bsdtar（libarchive）**，一个工具覆盖一大片；找不到再依次试 7-Zip、UnRAR。

实测：49 MB 的 `.7z` 和 186 MB 的 `.rar`（RAR5）都能直接导入，GBK 中文路径也解对了。

### 自动识别战役归属（可解释、不瞎猜）

大量玩家包根本不是 CCM 包：没有元数据、没有目录结构，就是塞满地图的 zip。
判定链按可靠度从高到低，**每一层都会告诉用户是凭什么判的**：

| 顺序 | 证据 | 精确？ |
| --- | --- | --- |
| 1 | 包内元数据的 `campaign` 字段 | ✅ |
| 2 | 包内镜像路径 `Maps/Campaign/void/…` | ✅ |
| 3 | **地图内部的依赖声明** `Void Story (Campaign)` | ✅ |
| 4 | 地图文件名前缀 `p*` | ⚠️ 启发式 |

第 3 层是这个版本的技术亮点：SC2 的 `.SC2Map` 是 MPQ 归档，完整解析成本很高，
但暴雪自己的依赖系统把战役依赖写在 `DocumentHeader` 里，而那通常是个 zlib 流 ——
展开形态直接读文件，单文件形态扫流解压即可。实测 7 个真实样本里 5 个 8/8 命中。

**威力在于地图可以取任意文件名**：把 `酒馆合作虫心` 的 6 张地图改名成 `stage01~06.SC2Map`
（不含任何 `t/z/p/n` 前缀）单独打包，照样靠依赖声明判出「虫群之心」。

四层都认不出来就**停下来问用户**，绝不瞎猜。手动指定永远可用，且优先级最高。

### 补丁：覆盖层 + 优先级 + 快捷开关

补丁不复制战役本体，在**铺盘那一刻**按优先级叠加：

`@text
第 0 层   data/campaigns/<战役>/<版本>/     战役本体
第 1 层   data/patches/<补丁id>/            priority 100
第 2 层   data/patches/<补丁id>/            priority 200
──────────────────────────────────────────────
合成 = 每个目标路径取"最高优先级那一层"的文件
`@

因此：补丁全程只存一份（**省空间**）、不改动任何原始层（**可恢复**）、
勾掉一个补丁只是重算一次清单（**开关快**）。

- 声明了 `requires` 的补丁可以「自动匹配」；没声明依赖的只能手动挂 —— 这是现实里的常态。
- 补丁元数据（名称/作者/注册 ID/描述/默认优先级）可以随时编辑。
- 可以单独导出一个补丁，也可以跟着战役一起导出。

### 导出成 CCM 也能读的包

`@text
黄金之遗.zip
├── metadata.txt            ← CCM 读这个
├── paiur01.SC2Map          ← 平铺的地图
├── HTXL.SC2Mod
└── Miyin/                  ← CCM 完全忽略
    ├── metadata.json       ← 我们的完整数据
    ├── bindings.json
    └── patches/<id>/…      ← 补丁原件
`@

**我们的数据全塞在 `Miyin/` 里**，所以同一份包既能被 CCM 读，也能被本启动器读回
（还能把补丁一起带走）。有「附加模式」和「合成模式」两种。

### 其他

- **版本与更新**：注册 ID、宽松版本比较、冲突时选「覆盖更新」或「重命名后导入」。
- **拖拽导入**：压缩包拖进窗口任意位置即可，走和点按钮完全相同的流程。
- **包格式规范**：[docs/package-format.md](../package-format.md) ——
  兼容 CCM 与「星际枢纽」标准，扩展放在 `miyin` 命名空间。

## 安装

下载 `SC2Miyin-Launcher-0.1.0-alpha.1-win64.zip`，解压后双击 `SC2Miyin Launcher.exe`。

- **免安装绿色版**，数据写在 exe 同级的 `data/`。
- 首次启动自动从注册表找星际争霸 II；找不到就在「设置」里手动指定。
- 升级只替换 exe，`data/` 留着。

## 已知限制

- 非 zip 格式依赖系统自带的 `tar.exe`；很老的 Windows 需要装 7-Zip。
- 导出时如果地图是**解开的目录树**形态，CCM 可能读不了（界面上会提示）。
- 第 3 层识别是**尽力而为**：MPQ 版本与压缩算法不同时可能扫不到，
  这时会干净地下落到第 4 层，绝不会把"扫不到"当成"没有依赖"。
- 还没有做：游戏运行时探测、从游戏目录反向导入、存档管理。
