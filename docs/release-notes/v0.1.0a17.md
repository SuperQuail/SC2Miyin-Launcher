# 0.1.0a17

**本版本为热修复版本：修复部分战役包导入后地图不生效、游戏里的战役没有任何变化的问题。**

## 问题

**现象**：像「机翻版（中文启动）」这种把整个 CCM 包套进游戏目录镜像的包
（`Maps/metadata.txt` + `Maps/*.SC2Map` + `Mods/…`），导入后看起来一切正常，
文件也铺进了游戏目录，但进游戏后那部战役没有任何变化。

**影响范围**：只影响「带元数据 + 游戏目录镜像布局 + 地图直接摆在 `Maps/` 根上」的包。
普通 CCM 包、无元数据包与别的镜像包不受影响。

## 本版本的处理

- 重新梳理了包内布局与文件落点的判定：先确定包的「内容根」与它是不是游戏目录镜像，
  再按一张固定的落点表决定每张地图 / 每个模组该装到哪 —— 地图不会再落到游戏不读的
  `Maps/` 根，而是按战役地图装进 `Maps/Campaign[/子目录]/`，模组照常进 `Mods/`。
- 顺带处理了一批边缘情况：模组自带的 `metadata.txt` 不再被当成包元数据；
  包内有多份元数据时会取最浅的一份并提示；两个文件会落到同一位置时会提前提示；
  没有元数据、外面多套一层包名目录的 `{Maps,Mods}` 包会正确剥掉包名那一层。

## 升级方式

覆盖可执行文件即可。本版本不改战役库、存档与配置，`data/` 目录内容保持不变。

**之前用旧版本导入过这类包的，需要重新导入一次** —— 旧记录里的落点不会自动修正。

## 关于本版本

- 没有界面改动；导入对话框可能多出一两条布局提示，属于正常现象。
- 没有修改战役包格式，旧包照旧可用；导入仍兼容 CCM / 星际枢纽 / 镜像包。
