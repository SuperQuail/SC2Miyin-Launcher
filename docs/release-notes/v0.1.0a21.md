# 0.1.0a21

游戏运行时不再拦截改战役；全部临时文件收进数据根 `temp/`；用户提示统一为书面语；战役页增加 Star 支持作者入口。

## 游戏运行时不再拦截

- 启用 / 停用 / 铺模组在游戏运行时照做，不再按进程探测预判。
- 文件被占用时弹原生确认框：继续 = 跳过该文件并处理其余文件；取消 = 停止本次操作。
- 跳过的文件仍留在安装清单，关闭占用程序后可重试；无人值守的同步直接停止，提示回到界面。

## 数据落盘统一

- 临时文件只进 `<数据根>/temp/`（更新包、工具安装包、WebView2 安装器、解包中转），启动时清空。
- 更新包固定暂存 `temp/updates/staging`，不再按版本号建目录；下载 / 解包失败自动清理。
- 工具安装包走 `temp/tools`，装好进 `tools/`；日志进 `logs/`。
- 7-Zip 解到 `tools/7zip-2605`，数据根不可写时退回 `%LOCALAPPDATA%`；崩溃日志优先 `logs/`。
- 启动器配置仍在 `%APPDATA%`，WebView2 profile 仍在 `%LOCALAPPDATA%`。
- 旧的 `<数据根>/updates`、`<数据根>/webview2` 启动时清理。

## 界面与文案

- 用户可见提示统一为书面语（错误串、原生对话框、界面文案），规则见 AGENTS §6。
- 战役页左上角、开始游戏按钮上方增加「点 Star 支持作者」金色点赞入口，打开
  https://github.com/SuperQuail/NeoBot/ 。

## 注意

- 启动会清空 `temp/`：下载完更新但没安装就重启，需要重新下载。
- 数据根不可写时，临时写入会按既有流程提示提权；7-Zip 与 WebView2 安装器有各自回退。
