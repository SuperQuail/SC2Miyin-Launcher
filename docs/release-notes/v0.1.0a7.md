# 0.1.0a7

**本版本为热修复版本。修复启动器与游戏安装于不同磁盘分区时，无法启用战役与模组的问题。**

## 升级方式

覆盖可执行文件即可。本版本不改动用户数据（战役库、存档、配置），`data/` 目录内容保持不变。

## 问题

**现象**：启动器与《星际争霸 II》安装于不同磁盘分区时，启用或停用战役、安装模组均失败，界面提示出错，游戏目录内容没有变化。

**影响范围**：仅影响启动器与游戏位于不同分区的用户；二者位于同一分区时不受影响。绿色版启动器默认安装于程序所在目录，因此将其与游戏放在不同磁盘（例如启动器在 C 盘、游戏在 D 盘）时会遇到该问题。

## 本版本的处理

启用或停用战役、安装模组时，启动器需要在游戏目录与自身数据目录之间移动文件。此前该步骤要求两者位于同一磁盘分区，现已取消该要求：

- 同一分区内沿用原有的移动方式，不产生额外的复制开销；
- 位于不同分区时，改为「复制到目标位置，确认完整后删除原文件」。

复制过程中如果出错，已写入的部分会被清理，不会在游戏目录里留下不完整的文件。

## 关于本版本

- 不包含界面改动。
- 不修改战役包格式；此前的战役包与模组包继续可用。
