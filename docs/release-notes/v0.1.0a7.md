# 0.1.0a7

这一版很小，只补一处：**打包没完的时候别让人走掉**。

## 打包没完就想走，会拦一下

一次导出要写几十秒到几分钟。中途离开（点返回、关窗口、刷新）留下的是**写了一半的包** ——
拿它去导入只会看到「包内没有 metadata.json」，而用户完全不知道是导出没写完。

所以离开这件事被改成**一次明确的取消**：

- **不取消** —— 关掉问句，留在页面上，导出照旧继续；
- **取消导出并离开** —— 后端在下一个文件写完时停手，**把写了一半的包删掉**，然后才放人走。
  取消不是"把界面关掉、后台接着写"：包要么是完整的，要么不存在。

三条路都拦住了：

| 怎么走 | 怎么拦 |
| --- | --- |
| 点「← 返回启动器」 | 自己的对话框：「还在打包 123/2331。离开就得先取消这次导出 —— **写了一半的包会被删掉**」，给「不取消」与「取消导出并离开」 |
| 关窗口（✕ / 任务栏） | 桌面壳的 `onCloseRequested` 拦下，弹同一个框 |
| 刷新 / 关标签页 | 浏览器级的 `beforeunload` |

## 流程约定

- **除非用户明确说明，不得发布 PR**：改动先待在分支上，等一句话再开。
- **代理不许代替维护者 merge**：开 PR、跑门禁、贴验证是代理的活，merge 只能由维护者自己做。
