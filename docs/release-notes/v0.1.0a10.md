# 0.1.0a10

修复一个会把启动器换坏的更新事故。

## 更新器不再把 CLI 附件当成更新包（重要）

a9 把 miyin-cli 作为第二个附件发出去，而更新器挑更新包只认「文件名以 -win64.zip 结尾」，
CLI 附件正好也符合 —— 它排在前面时就会被下下来，解包后拿 miyin-cli.exe 顶替启动器，
结果就是双击启动器打开的是命令行工具。

两道闸都补上了：

- 挑附件时**排除带 -cli 的那个**；只有 CLI 时宁可不更新，也不拿它顶替。
- 解包时**不把 CLI 当启动器**；包里只有 CLI 就明确拒绝。

另外 a9 那个 CLI 附件也已经改名成 miyin-cli-0.1.0a9.zip —— 名字不再符合旧版更新器的挑选规则，
所以还在用 a8/a9 的人从 a9 升级也不会再中招。

## CLI 仍然是单独附件

miyin-cli 只给开发者与 agent 用，不在主包里，下载在发行版的附件列表里（miyin-cli-*.zip）。
