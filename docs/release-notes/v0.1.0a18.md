# 0.1.0a18

**本版本为功能与体验更新：已知复刻战役的入口地图自动识别、导入时可改战役名、启动改走暴雪战网，并修掉了长弹窗无法滚动的问题。**

## 新功能

- **自动识别更多复刻战役的入口地图**：内置预设新增「群雄纪元」
  （社区复刻战役改版 `SCMR RPG Campaign Launcher`，优先于原版复刻战役），
  并加了通用 `Launcher` 兜底（只认包根、大小写不敏感）。预设数据已抽成独立文件，
  以后加预设只改数据、不动匹配逻辑。
- **导入时可改战役名**：导入页的「战役名称」可直接编辑；一次导入多个包时每一行都能各自改名。
- **没有声明依赖的包默认收集全部模组**：包里没有元数据、或元数据没写 `mods=` 时，
  导入会把包内所有模组默认记为依赖；作者写了就按作者声明来。
  导出时依赖会写进 `metadata.json`，再导入到别处也能识别。
- **自制战役右键菜单**：版本卡片右键现在可以直接「编辑信息…」，
  导出也走完整的导出向导（弥音包 / 星际枢纽兼容包、可合并补丁）。

## 改变

- **「开始游戏」改为启动暴雪战网**：直接启动星际争霸会停在未登录状态、无法游玩；
  现在先打开战网，登录后从战网进入游戏。找不到战网客户端时会给出明确提示。
- **主地图解析结果如实标注为推测**：自动选出的主地图会提示
  「主地图为推测结果，如果启动错误请询问发布者或查看文件以获知正确的主地图是什么」。
- **导入页文案重写**：去掉「包内没写」这类口语化描述，按钮与动作统一为「导入」。

## 修复

- 编辑信息、导出等长弹窗超出屏幕且无法滚动：现在弹窗最高占一屏，
  内容区单独滚动，标题与「取消 / 保存」固定在可见位置。

## 升级方式

覆盖可执行文件即可。本版本不改战役库、存档与配置格式，
`miyin_launcher_data/` 里的内容保持不变。

**注意**：本版之前导入的版本不会自动补「依赖模组」记录；
需要的话可以在「编辑信息」里手动勾选，或重新导入一次。
