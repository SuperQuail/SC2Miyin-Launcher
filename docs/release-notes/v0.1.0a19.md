# 0.1.0a19

**本版本加入「战役转盘」与「战役数据库」：从已有战役或 98 部资料库战役中抽取一部，按资料卡查看内容并直达下载源。**

## 新功能

- **战役转盘**：顶栏新增「转盘」页，分为「已有战役 / 战役数据库」。
- **已有战役**：直接读取战役库，支持按资料片/具体战役筛选；默认剔除原版；可配置自动应用、剔除已抽取、重置抽取状态。
- **战役数据库**：内置 98 部战役资料，支持按类型/具体战役筛选；抽中后显示资料卡（标题、类型、作者、描述、下载源、作者关联）。
- **下载源直达浏览器**：资料卡里的网盘链接会交给系统浏览器打开，不在 WebView 内跳转。
- **数据库数据区**：`ui/src/data/campaign-db/{wol,hots,lotv,nova,custom}/`，一个 JSON 对应一部战役；新增资料后重新构建即可收录。

## 改变

- 已有战役转盘中，原版战役默认不参与抽取。
- 转盘页统一使用书面化、无解释性语言的前端文案。

## 修复

- 补丁面板补上删除按钮与确认流程（此前只能导入、无法删除）。

## 已知限制

- 战役数据库全量上盘时，98 个扇区的编号会明显密集。
- 网盘链接未做存活校验；部分仅含链接的资料来源没有作者或详细描述。

## 升级方式

覆盖可执行文件即可；战役库、存档与配置格式不变，`miyin_launcher_data/` 内容保持不变。
