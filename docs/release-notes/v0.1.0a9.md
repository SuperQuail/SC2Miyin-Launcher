# 0.1.0a9

数据搬家、安装页重做、提示重做，外加一个新工具 miyin-cli。

## 战役库搬到游戏目录旁边（重要）

数据根从「启动器旁边的 data/」改为**星际争霸安装目录同级的 miyin_launcher_data/** ——
同一台机器上所有启动器实例共用一份战役库。

- 旧数据**启动时自动搬过去**（同盘 rename，跨盘复制后删源）；新位置已经有内容就一律不动，只写日志。
- 搬到一半失败会停在 .partial，下次启动接着来；半份数据不会被当成完整库。
- **发现另一份数据**（比如你拷了第二个启动器）会弹对话框：逐个冲突选「保持游戏目录那份 / 用本地这份 / 两份都留」。

## 安装整合包独立成页

- 拖进包先**预检**：认得出归属就自动填，认不出才让你选（自动识别的结果会标「推断」+ 可信度依据）。
- **一次拖多个包可以一起装**：逐个预检、每行能单独改归属、一个失败**不中止**整批、装完给汇总。
- 单个包时是带封面的居中属性表。

## 右下角提示重做

卡片式、语气收在图标徽章上、可堆叠（最多同时 3 条，旧的压暗只露头）、
鼠标压上去暂停消失、点 ✕ 只关那一条、切页不丢。

## 战役卡片拖动排序

战役菜单里的**玩家版本卡片**与**自制战役页的卡片**可以拖动排序（记得住）。
官方四大战役的顺序是固定菜单，拖不动 —— 这是刻意的。

## 导航

位置进了 URL（你看不见，但它让刷新不丢、装完/返回能回到原来的页面与战役）。

## 新工具：miyin-cli

作为**单独附件**提供（`SC2Miyin-Launcher-0.1.0a9-cli-win64.zip`）—— 它是给开发者与 agent 用的，普通玩不需要，所以不在主包里。输出机器可读的 JSON：

    miyin-cli inspect <包>...              完整解析结果
    miyin-cli identify <包>                归属判定（认不出来就如实说不知道）
    miyin-cli placements <包> --slot wol   每个文件会落到游戏目录的哪个位置
    miyin-cli compat <包>                  对比「按枢纽装」与「按我们的约定装」各自哪些文件会被识别

退出码：0 全部可安装 / 1 有问题 / 2 参数错。说明见 docs/cli.md。

## 修复

- 「打开目录」改用 Windows Shell API —— 以前会跳到「文档」；失败现在会明确报错，不再静默。
- 启用战役后不再弹回战役列表。
- 安装完成 / 点返回都回到进安装页之前那一页。
- 依赖模组误报、未启用战役的 mod 显示成挂载。
