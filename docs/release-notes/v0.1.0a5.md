# v0.1.0a5 —— 战役与模组的版本管理

> 预发行版。这一版主要做**自制战役与模组的版本管理**，顺带修掉几个会让人以为「装了但没装」的问题。

```text
30 个提交，全部围绕一件事：让「同一个战役 / 模组的多份版本」能共存、能切换、能对比。
```

## 一、模组终于像个「包」了

以前模组只是一堆文件，导入进来就完了。现在它有身份、有版本、有元数据：

| 概念 | 作用 |
| --- | --- |
| `modid` | 决定「这是同一个模组的新版本，还是另一个模组」 |
| 内容指纹（SHA-256） | 判定「完全一样」，一样就不留第二份 |
| `folder` / `kind` | 铺进游戏目录时用什么名字、铺成文件还是目录 |

导入时按四条规则处理：

```text
库里没有这个 id          -> 新模组
有，内容一模一样          -> 不留第二份，直接用库里那份
有，版本号不同            -> 作为新版本，可自由切换
有，版本号相同但内容不同  -> 自动改个版本号再存
```

**版本号优先用包内声明的**。没声明才从库里已有的推 —— 推出来的多半跟上一版同号，于是自然走到「撞号改名」那条路。
不知道版本就老实说不知道，别硬安一个。

库里已经有同 id 时会**问一句**：作为新版本，还是作为独立改版（拿别人模组改的那种）。

## 二、战役也能改元数据了，版本号带校验

- 战役页的编辑框以前**根本没有版本号字段**，现在能改，而且格式校验放在后端：必须数字开头、分段只能是 `.` 和 `-`、不许有空格。界面上边打字边提示。
- **注册 ID 不再让用户手打**：按「作者名.战役名」自动拼（`naming::registration_id`）。规则只放 Rust 一份，界面通过命令实时问 —— 本地 IPC 不到一毫秒，比两边各写一套然后慢慢漂移好。中文保留，不硬转拼音。

## 三、模组对比与选择性导出

装了 SC2Diff（启动时自动静默安装，失败提示一次后不再重试）之后：

- 同一个模组的两个版本可以**对比**：文件级差异 + 对能比较的文档跑语义 diff
- 导出时**勾选要带哪几个版本** —— 一个模组攒了十几个版本之后全打包又大又没人要

## 四、修掉的「装了但没装」

这几个都是**拿真包跑出来的**，单元测试一个都没拦住：

### 模组丢了文件夹层级

`Alenger` 被自作主张改成 `Alenger.SC2Mod`，而地图里写的是 `Mods\Alenger\1钢铁.SC2Mod` —— 名字对不上，游戏找不到。

### 自制战役导入报「未知的战役槽位」

槽位校验多加了「只放行原版四大战役」的过滤，`custom` 被挡在门外。自制战役是独立的一类，落盘位置本来就分开管，校验这一层不该再判断它属于哪部原版战役。

### 复刻战役的地图被拍平

「星际争霸：复刻战役」这类包是**按游戏根目录摆的**（根上有 `Mods/`，兄弟目录就是 `Maps/` 底下的）。以前把里面的章节目录当成作者的分类目录拍平了，于是启动器地图按相对 `Maps/` 的路径找下一关全部落空 —— 用户看到的是「能打开启动器，但点哪一关都进不去」。

### 自己的白名单把正确落点拒了

白名单原来只放行 `Maps/Campaign` 和 `Maps/CustomCampaigns`，而修好落点之后地图要去 `Maps/Starcraft Mass Recall/…`，被自己的闸门拒绝。现在是 `Maps` / `Mods` / `Interfaces` 三个**根**。

### 1.4 GB 的包导入要 34 秒

列个清单就把整个包解到临时目录，而一次导入要开三次 —— 等于解了三遍。现在按需读（`tar -tf` 列清单、`-xOf` 读单条），真要全部落盘才解一次：

```text
预检        11019 ms  ->    473 ms
导入        22794 ms  ->  11598 ms   （剩下的是真解压，约 120 MB/s）
合计          ~34 s   ->    ~14 s
```

## 五、界面

- **自绘标题栏能拖窗口**：去掉原生边框后 `data-tauri-drag-region` 需要权限，而 `capabilities/` 目录压根不存在。现在整条顶栏（除按钮）都是拖动区。
- **右键菜单补齐**：模组行、模组页、战役页、自制战役页各有各的功能。
- **自制战役能停用了**：以前装进去就卸不下来。
- 解压时不再闪控制台窗口。

## 六、测试系统

这一版把测试补成了三层，因为**上面那些问题没有一个被单元测试拦住**：

```text
crates/miyin-core/tests/packages.rs   自己造包的端到端（导入 -> 启用 -> 检查游戏目录实际长什么样）
ui/src/**/*.test.ts                   前端接线测试（专治「emit 了但父组件没接」）
scripts/check.ps1                     一键门禁，六项，任何一项失败就非零退出
```

端到端测试**自己造包**，不依赖任何真实战役包 —— 那些是游戏版权内容，不进仓库，别人 clone 下来也跑不了。
