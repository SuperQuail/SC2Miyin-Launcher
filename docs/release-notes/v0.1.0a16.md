# 0.1.0a16

**本版本为热修复版本：修复部分战役包导入后模组丢失、游戏里进不去关卡的问题。**

## 问题

**现象**：像「叛逃皇卫完结版」这种把 `Maps/` 和 `Mods/` 放在同一个包名目录下、
但 `metadata.txt` 又放在 `Maps/Campaign/` 里的战役包，导入后看起来一切正常，
实际只装进了地图 —— `Mods/` 里的模组一个都没进库。地图里写死的模组依赖找不到，
游戏里自然进不去关卡。

**影响范围**：只影响「带元数据 + 游戏目录镜像布局 + 外面多套一层包名目录」的包。
普通 CCM 包、无元数据包和别的镜像包不受影响。

## 本版本的处理

- 导入时改为按**布局**判断包的内容从哪一层开始：从包根往下，第一个直接放着
  `Maps` / `Mods` / `Interfaces` 的目录就是内容根。
  `metadata.txt` 只负责提供战役名、作者、版本与归属，不再决定内容边界。
- 这类包的 `Mods/` 会照常进库，启用时和地图一起铺进游戏目录。

## 升级方式

覆盖可执行文件即可。本版本不改战役库、存档与配置，`data/` 目录内容保持不变。

**之前用旧版本导入过这类包的，需要重新导入一次** —— 旧记录里缺的模组不会自动补回。

## 关于本版本

- 没有界面改动。
- 没有修改战役包格式，旧包照旧可用；导入仍兼容 CCM / 星际枢纽 / 镜像包。
