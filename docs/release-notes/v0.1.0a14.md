# 0.1.0a14

**修掉「窗口右上角的三个按钮会消失」的问题。** 窗口拉窄（默认 1200 宽也可能中招）、笔记本开了 125%/150% 缩放、或者顶栏多出「新版本」提示时，最小化 / 最大化 / 关闭会整组跑到窗口外面看不见 —— 而窗口边框是启动器自己画的，按钮没了就只能靠 Alt+F4 或任务管理器。

## 升级方式

覆盖可执行文件即可。战役库、设置与存档分别在游戏目录同级的 `miyin_launcher_data/` 和「我的文档」里，本版升级不动它们。

## 本版本的处理

顶栏现在会**随窗口宽度收放**：

- 窗口按钮和页签**永远保留**，优先收起的是信息类标签：SC2 版本 → 演示标记 → 「新版本」徽标的文字（只留下载图标，悬停仍能看到版本号）→ 启动器版本 → 品牌副标题。
- 三个窗口按钮贴齐窗口右边，不再被切掉一截（宽窗口下以前会切掉关闭按钮的一部分）。
- 极小宽度下页签可以横向滚动，不会再把按钮顶出去。

## 另外

- **移除了顶栏的「资源网站」入口**（该站点已不再提供）。

## 关于本版本

- 有界面改动（顶栏布局随宽度自适应）。
- 没有改战役包格式，旧包照旧可用。
