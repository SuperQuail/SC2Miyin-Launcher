# 前端迁移：Vue → React

> **✅ 迁移已完成（2026-10）。** 用户侧与开发者页现在都是 React 18，Vue 已从依赖里移除，
> `ui/src` 下没有 .vue 文件。本文保留为**过程记录**：它记的是当时怎么切、切的时候踩了什么坑。
> 最终结构见 AGENTS §4 与 §18。

> **方向已定**：逐步迁移，最终**弃用 Vue**，用户侧也换成 React。
> 本文写怎么迁、按什么顺序迁、以及**别把 Vue 那套坏习惯带过去**。

## 为什么迁

- 一开始选 Vue 是因为参考项目（scnexus）是 Vue，能直接复用它的组件组织与 store 划分。
- 但开发者页用的是 JetBrains 官方 Ring UI，那是 **React 组件库** —— 于是这个项目**本来就在同时维护两套框架**。
- 两套框架意味着：两套心智、两套构建、两套坑（见 AGENTS §18 那张表），而**没有一处**因此变得更好。
  合并成一套，长期看只赚不赔。

## 迁移策略

**整块替换，不逐文件混写。**

- 一个视图 / 一个面板**整体**换成 React 挂载点，用一次 PR 完成。
- **不要**在同一个文件里混用两套框架 —— 那种"过渡态"没人愿意读，也没人敢删。
- 迁完就**删掉旧的 Vue 文件**，不要留在仓库里当"参考"。

**顺序：从"独立、边界清楚、改动频繁"的开始。**

| 顺序 | 目标 | 理由 |
| --- | --- | --- |
| 1 | `SettingsView` | 全是表单与说明文字，交互简单，最适合练手 |
| 2 | `ModsView` | 独立页面，状态基本自洽 |
| 3 | `CampaignsView` + `SlotMenuView` + 各自的卡片/面板 | 主体流程，最大的一块，放最后 |
| 4 | `App.vue`（顶栏 / 页签 / 弹窗宿主） | 壳，换掉它等于换掉入口 |

**中间层原样搬走**：`ui/src/api/*`（bridge / types / art / markdown）里**不 import `vue`**，
迁移时不用重写；`useLauncher` 这类 composable 里"与框架无关的那部分"先抽出去
（它现在是 Vue 的 `ref`，抽成纯函数 + 一个薄薄的 React hook 包装）。

## 迁移时**不要**照搬的东西

1. **单文件几百行的组件。** 现在的 `ModsView.vue` 1300+ 行、`SlotMenuView.vue` 1100+ 行 ——
   那是"一个文件里塞了列表 + 卡片 + 弹窗 + 右键菜单 + 状态机"。
   迁过去时**按职责拆**：列表一个组件、卡片一个、弹窗一个、右键菜单一个。
   （这也是 AGENTS 里那条"超过 500 行就告警"的门禁想说的话。）
2. **组件里散写颜色。** 现在有一部分颜色直接写在 `<style scoped>` 里。
   迁移时一律走 `tokens.css` 的令牌 —— 换主题时才不用满仓库找颜色。
3. **"一页一个大状态对象"。** `useLauncher` 现在什么都管（安装、战役、模组、存档、更新、主题）。
   迁到 React 时按领域拆成几个 hook：`useLibrary` / `useMods` / `useSaves` / `useUpdate` / `useTheme`。
4. **自己拼的弹窗/下拉。** 现有的 `.sheet` / 右键菜单都是手写的。
   迁过去可以用 Ring UI 的对应控件（注意 §18 里那张坑表），或者至少抽成**一个** `<Sheet>` 组件，
   而不是每个弹窗各写一份遮罩 + 定位。

## 顺带赚到的

- **两侧共用一套控件**：开发者页已经在用 Ring UI（React）。迁完之后用户侧也能用它 ——
  现在用户在 Vue 里手写的那些按钮 / 字段 / 弹窗，可以换成同一套组件，
  `ui/src` 里那 3600 多行**组件内联 CSS**（占前端总量约 28%）能压下去一大截。
- **少一套构建**：现在 `pnpm -C ui build` 要跑两次（两个入口分开构建，原因见 §18）。

## 迁移期间的红线（AGENTS §18 仍然有效）

- 两个入口**同时活着**（`index.html` 用户侧、`ide.html` 开发者页），谁也别 import 谁。
- 共享的只有**框架无关的纯 TS**：共享文件里**不许出现 `vue` 或 `react` 的 import**。
- 构建还是**两次**、顺序不能乱（原因见 §18：公共块预加载会把用户侧打白屏）。
- 新写的界面**优先 React**；只有"给现有 Vue 组件做个小修"才继续写 Vue。
