弥音启动器 MiYin Launcher —— 测试版
======================================

怎么用
------
1. 双击 miyin-launcher.exe 即可，无需安装、无需任何运行环境（前端已内嵌）。
2. 首次启动会自动从注册表找星际争霸 II；找不到就在「设置」里手动指定游戏根目录
   （即包含 StarCraft II.exe 的那一层）。
3. 启动器自己的数据放在 exe 同级的 data/ 目录里。整个文件夹拷走就换了台机器，
   不会污染游戏目录。换新版本时只替换 exe，data/ 留着，导入过的战役不会丢。

导入（三种方式都行）
--------------------
· 点「＋ 导入战役包」选文件
· 直接把压缩包拖到窗口里（拖到哪个页面都行，会自动切回战役页）
· 支持 zip / 7z / rar / tar / gz / bz2 / xz / zst / cab / iso，不用先转格式

导入时会显示信息来源：
  「包内声明的资料片」   = 读了 metadata，以数据为准
  「自动识别（尽力而为）」= 没有元数据，靠证据链推出来的，会写明依据
  「无法识别」           = 需要你手动选
目标战役的选择始终可以改，自动识别只是默认值。
库里已有同名/同 ID 版本时，会让你选「覆盖更新」还是「重命名后导入」。

点进某个战役之后
----------------
· 「编辑信息」改名称 / 作者 / 注册 ID / 描述（只改启动器记录，不动包内容）
· 「导出包」「导出（含补丁）」导出成 CCM 也能直接读的 zip
· 下方「补丁」面板：
    - 勾选开关：启用/停用，关掉即撤销，随时可恢复
    - 优先级：数字大的后覆盖
    - 「编辑」改补丁的名称/作者/ID/描述/默认优先级
    - 「导出」把单个补丁导成独立的补丁包
    - 「移出」从当前战役上摘掉
    - 「挂载补丁」挂上库里已有的；「自动匹配」按依赖自动挂

补丁是覆盖层：不复制战役本体，启用时按优先级叠加，所以既省空间又能随时开关。
补丁包在战役列表页导入（会提示到对应战役里挂载）—— 它本身不归属任何战役。

已知限制
--------
· 非 zip 格式靠系统自带的 tar.exe（Windows 10 1803+ 自带）解压；
  很老的 Windows 需要装 7-Zip。
· 导出时如果地图是解开的目录树形态，CCM 可能读不了（界面上会提示）。
· 自动识别的可靠度：元数据 > 包内路径 > 地图内依赖声明 > 地图文件名。
  前三条是精确证据，最后一条是启发式。认不出来时不会瞎猜，会请你选。
