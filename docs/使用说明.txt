SC2Miyin Launcher · 弥音启动器 —— 0.1.0a2 测试版
==============================================

怎么用
------
1. 双击 miyin-launcher.exe，免安装、免运行环境（前端已内嵌）。
2. 首次启动会自动从注册表找星际争霸 II；找不到就在「设置」里手动指定游戏根目录
   （即包含 StarCraft II.exe 的那一层）。
3. 数据写在 exe 同级的 data/。整个文件夹拷走就换台机器，不污染游戏目录。
   换新版本只替换 exe，data/ 留着，导入过的战役不会丢。

这一版的新东西：自动更新
--------------------------
设置页最上面新增「更新」面板：检查 → 下载（带进度条）→ 安装并重启，
不用再去 Releases 页面手动找包。

网络部分会自动处理国内的情况：
· 代理按「环境变量 → Windows 系统代理 → 直连」自动挑，界面会显示当前走的哪条路
· 代理被 GitHub 限流时（国内代理多是共享 IP，容易撞上）会自动改直连重试
· 下载时把 release 资产展开成「直连 + 6 个镜像」，并发开跑，谁先下完用谁

代理模式、镜像加速、是否接收预发行版本，都能在设置页改。

这一版可以测什么
----------------
· 导入：点按钮选文件，或直接把压缩包拖进窗口
  - zip / 7z / rar / tar 都行，不用转格式
  - 面板会显示信息来源：「包内声明的资料片」= 读到了元数据；
    「自动识别（尽力而为）」= 没元数据、靠证据链推的，会写明依据
  - 目标战役始终可以改，自动识别只是默认值
· 点进某个战役：编辑信息 / 导出包 / 补丁面板（开关、优先级、编辑、导出）
· 设置页 → 更新：检查更新（当前已是最新版，应显示「已经是最新版本」）

★ 想完整验证「自动更新」：请用旁边的【更新测试-0.1.0a1】包
   那个是旧版本，启动后点检查更新会真的发现 0.1.0a2、下载并把自己换掉。

已知限制
--------
· 非 zip 的战役包靠系统自带的 tar.exe（Windows 10 1803+）解压；老系统要装 7-Zip。
· 导出时如果地图是「解开的目录树」形态，CCM 可能读不了（界面会提示）。
· 自动识别认不出来时不会瞎猜，会请你手动选。
